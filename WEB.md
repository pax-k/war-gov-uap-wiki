# war.gov/UFO Knowledge Graph

*A citation-grounded, cross-linked wiki compiled from declassified UAP / UFO primary-source documents.*

![](kg.png)

## What this is

A knowledge graph compiled from the declassified Unidentified Anomalous Phenomena (UAP / UFO / "Flying Disc") record released at **war.gov/UFO** and adjacent NARA / FOIA holdings — FBI files, State Department cables, NASA crew debriefings, USAF intelligence directives, Project SIGN incident summaries, US Navy mission reports, and a handful of openly-published civilian reports.

The goal: turn ~110 OCR'd primary-source bundles into a navigable, queryable knowledge base where **every claim links back to a primary source**. Pages are not chat transcripts or summaries — they are pre-compiled declarative knowledge, written once and kept current, with explicit `[[wikilinks]]` weaving people, programs, sightings, and concepts into a single graph.

Start at [[entities/fbi-hq-62-83894-file]].

The Apollo 11 "second look" cylinder (multi-witness, instrument-mediated, alternative-eliminated) is the strongest astronaut-class anchor in the corpus. See [[concepts/orbital-uap-sighting]].

## How pages are structured

Every page carries the same frontmatter:

- `title`, `category`, `tags` (≤5 canonical, drawn from a controlled vocabulary)
- `sources` — list of primary-source documents the page is compiled from
- `summary` — ≤200-character one-liner used in the index and graph hover
- `provenance` — `extracted` / `inferred` / `ambiguous` ratio
- `base_confidence` — 0.0–1.0
- `lifecycle` — `draft` / `stable` / `deprecated`
- `created`, `updated` — UTC timestamps

Inferred claims carry an inline `^[inferred]` marker. Ambiguous claims are marked `^[ambiguous]`. Verbatim source extracts are quoted in blockquote with page anchors.

## Sources & license

All wiki content is compiled from US Government declassified materials (public domain) and a small number of openly-published reports (COMETA, civilian-research clippings — fair-use citation). Every page lists its source documents in frontmatter under `sources:`; the SHA-256 hash of each ingested document is tracked in the wiki manifest for idempotency.

## How this was built

Built on the [obsidian-wiki](https://github.com/Ar9av/obsidian-wiki) framework — a skill-based system where everything is markdown instructions any AI coding agent can read and execute. No scripts, no dependencies, no infrastructure beyond a vault directory and a configured agent. See the project [[README]] and `AGENTS.md` for the full ingestion pipeline.
