### Range-fouler debrief document class — anchored at N=1 ([[references/dow-uap-d58-range-fouler-debrief-2020-10|d58]]) ^closed-by-dow-uap-d58 (template-anchor)

The `*-range-fouler-debrief-*` document class is the **third top-level mission-record class** in the dow-uap corpus (alongside USMTF GENTEXT/UAP mission reports and CTG-narrative mission reports). **Class structure anchored at N=1** with d58 establishing a complete template:

- **Document title `# Range Fouler Debrief Form`** — first explicit fielded-form artifact in the corpus.
- **Fielded schema, not narrative format** — pre-printed fields with witness-completed values. Distinct from USMTF GENTEXT/UAP (narrative segment) and CTG-narrative (BLUF / Timeline / Weather / Comments sections).
- **Defined identity block**: Last Name, First Name, Rank, Squadron, Crew Position, SIPR Email Address.
- **Defined event metadata**: Date (mm/dd/yy), Time of detection (hh:mm:ss Z), Day/Night, Side No., Buno, Mission Description (CAS, BFM, DCA, etc), LFE (Large Force Exercise) flag.
- **Defined position grid**: Contact Working Area, Contact Latitude / N-S, Contact Longitude / E-W, Contact Altitude, Altitude-Constant flag, Wind Direction-from at Contact Altitude, Wind Speed, "Was the contact moving?" + Direction/Speed.
- **Defined sensor + track grid**: Radar Equipped (option set), Stable Trackfile flag, # Contacts in "Group", AIM-9x Self-Track flag, ATFLIR Autotrack flag, Tally Achieved flag.
- **12-category morphology checkbox grid**: Round, Square, Balloon-shaped, Wings/Airframe, Other Shape, Apparent Propulsion, Moving Parts, Metallic, Markings, Translucent, Opaque, Reflective.
- **Free-text narrative block** — witness's own description; fallback for things the schema doesn't cover. d58's narrative carries the headline material (KINGPIN tasking, 16.9 NM standoff, intra-group circling, 1/30-s disappearance, noise jamming reception).
- **Submission-instruction block** with **filename schema** `Date_Squadron_RF.pdf` (first explicit submission-naming convention in the corpus) + email-to address (FOIA-`(b)(6)` redacted) + display-tape `.wmv` upload requirement (first explicit sensor-tape preservation directive).

- **Navy-aviation form template** — the pre-printed `AIM-9x Self-Track` + `ATFLIR Autotrack` sensor schema and the `VFA-106 HUD.wmv` template example filename collectively anchor the form in the Navy F/A-18 community. ^[inferred] First explicit Navy-aviation FRS template attribution in the corpus.
