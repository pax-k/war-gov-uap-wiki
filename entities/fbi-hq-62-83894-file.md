# FBI HQ File 62-HQ-83894

A large, multi-year **FBI Headquarters file** under Class **62** (the FBI's catch-all *"administrative miscellaneous"* classification). ^[inferred] Indexed and serialized at FBI HQ in Washington — distinct from the field-office 100-class case files in the wiki's existing FBI corpus (e.g. Detroit `100-26505`, Detroit `100-18221`). ^[inferred] Declassification of the file's content is *"derived from the FBI Automatic Declassification Guide, issued 24 May 2007"*. ^[extracted]

This page is the **parent-file hub** for a planned **17-serial wiki ingest series**. Serial 403 is the first artifact ingested. ^[inferred] The remaining ~16 serials (164, 220, 438, 449, plus sections 1–10 and sub_a) will be ingested in subsequent passes.

## What 62-HQ-83894 appears to be

From the **single serial 403 alone**, the most economical reading is that 62-HQ-83894 functions as a **content-monitoring / topic-clearinghouse file** at FBI HQ — i.e. a file in which HQ clips and serializes publicly-available materials (book jackets, magazine articles, newspaper clippings) about a topic the Bureau is tracking. ^[inferred] Serial 403 is a **clipped publisher's book jacket** (Gray Barker's 1956 *They Knew Too Much About Flying Saucers*, see [[references/fbi-hq-62-83894-serial-403]]), filed alongside an FBI Records Center routing slip with no FBI-authored investigative content.

This categorical claim is **inferred from one serial out of an unknown total** and should be revisited as more serials ingest. ^[inferred] Plausible alternative readings the remaining 16 serials may resolve toward:

- **UAP-as-public-discourse clearinghouse** — books, articles, periodicals about saucers, with no person-specific focus.
- **Civilian-saucer-researchers-as-class topic file** — Gray Barker, [[entities/oklahoma-ufo-research-association|OUFORA]], NICAP, APRO, et al. cross-filed.
- **Person-specific monitoring file on Gray Barker** — though this would be unusual for a Class-62 file (HQ Class 100 / 105 internal-security files would more naturally hold person-specific material). ^[inferred]
- **Mixed-content file** with multiple sub-functions across its lifetime, common in long-running HQ files. ^[inferred]

## Position in the FBI corpus

This is the **first HQ-level FBI artifact in the wiki**. ^[inferred] All prior FBI material in the wiki is **field-office product** — Detroit field-office files in 1957–66 ([[references/fbi-detroit-100-26505-krasuski-1957]], [[references/fbi-detroit-100-18221-serial-844-1958]]), and modern (2023) FD-302s of unknown field-office attribution ([[references/fbi-fd302-drone-pilot-redacted-2023]], [[references/fbi-fd302-serial-3-driver-redacted-2023]]). The HQ-level / clipped-publisher-content combination is structurally distinct from any prior FBI artifact in the corpus. ^[inferred] See [[entities/fbi]] for the full cross-era table.

The **content-monitoring** function (if confirmed by later serials) is also structurally novel for the corpus. ^[inferred] The wiki's prior FBI artifacts all document **agent-driven action** — interviews, citizen-call routing, civilian-org redirects, evidentiary intake. A topic-clearinghouse file documents instead **HQ's choice of what to clip and keep**, which is a meaningfully different category of FBI behaviour to study.
