# UAP

A research project distilling declassified primary-source archives on Unidentified Aerial Phenomena (UAP, formerly UFO / "Flying Discs") into structured, cross-linked wiki pages.

## Scope

- **Primary sources**: declassified US government bundles dropped into `_raw/` and processed by `wiki-ingest`, plus more recent agency-style briefings dropped into `sources/`.
- **Output**: concept / entity / reference / synthesis pages, plus this project overview.
- **Cross-cutting questions**: how the institutional UAP investigation regime evolved; which sightings have signatures that resist conventional explanation; which entities (people, programs, bases) recur across decades.
